# JIZO｜地藏小王：靈島守護錄 REMASTER V3.2

GitHub Pages 內部測試版。

## 檔案
- `index.html`：完整遊戲主檔，音樂與圖片皆已內嵌，可單檔執行。
- `README.md`：專案說明。

## GitHub Pages 發布
1. 將 `index.html` 與 `README.md` 上傳到 repository 根目錄。
2. 進入 **Settings → Pages**。
3. Source 選 **Deploy from a branch**。
4. Branch 選 **main**，Folder 選 **/(root)**。
5. 儲存後等待 GitHub Pages 完成部署。
